# Filters

One filter = one file here: `public/filters/<id>.js`. If a filter needs more files (a test, a
lookup table, notes), make it a folder instead: `public/filters/<id>/filter.js`.

Nothing else has to change. The app finds filters on its own (`filters/index.json` is generated by
`npm run dev` and `npm run build`), adds them to the **Filter** menu, sorted by name, and shows
sliders for their parameters. `npm run check` validates every filter.

## A filter file

```js
export default {
  apiVersion: 1,
  id: 'two-tone',                 // kebab-case, equal to the file (or folder) name
  name: 'Two-tone',               // shown in the Filter menu
  description: 'Pure black and white, split at a brightness level.',   // shown under the menu
  params: [                       // optional sliders
    { id: 'level', name: 'Level', min: 0.05, max: 0.95, step: 0.01, default: 0.5, format: 'percent' },
  ],
  glsl: `
vec3 applyFilter(vec2 uv, vec3 color) {
  return vec3(step(p_level, luma(color)));
}`,
};
```

The filter runs on the GPU for every pixel, in WebGL 1 (GLSL ES 1.00). `glsl` must define
`vec3 applyFilter(vec2 uv, vec3 color)` and may define helper functions above it.

| Available in `glsl` | What it is |
|---|---|
| `color` | this pixel after the brightness/contrast/… sliders, RGB 0–1 |
| `uv` | this pixel's position in the source image, 0–1 |
| `src(vec2 uv)` | any other source pixel (with the sliders applied), for neighbourhood filters |
| `u_texel` | the size of one source pixel in uv units, e.g. `src(uv + vec2(u_texel.x, 0.0))` is the pixel to the right |
| `luma(vec3 c)` | brightness of a colour, 0–1 |
| `p_<id>` | the value of each parameter, as a `float` (`p_level` above) |

Return the new colour; it is clamped to 0–1. Rotation, mirroring and zoom happen outside the
filter, so `uv` always refers to the unrotated camera image.

Parameter fields: `id` (camelCase, becomes `p_<id>`), `name`, `min`, `max`, `step`, `default`, and
optionally `format`: `number` (default), `percent` (0–1 shown as %), `degrees`.

## Checking a new filter

1. `npm run check` validates the file's shape.
2. `npm run dev`, open http://localhost:8080 and pick the filter. If the GLSL does not compile, the
   app switches back to Original and the browser console shows the compiler error.

Filters only change how the picture looks. Anything that needs to understand a specific camera's
data (like thermal cameras) is a driver, see `public/drivers/README.md`.
